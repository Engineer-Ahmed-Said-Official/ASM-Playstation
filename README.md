## 📖 حول البرنامج

**ASM Playstation** هو نظام محاسبي وإداري متطور وشامل، تم تصميمه خصيصاً لإدارة صالات ألعاب البلايستيشن والكافيهات ومراكز الترفيه بأعلى كفاءة وسرعة، مع استقرار تام وخفة فائقة في استهلاك موارد الجهاز.

يتميز البرنامج بواجهة Dark/Cyberpunk عصرية ومريحة للعين، مع تحكم آلي في تشغيل وفصل الطاقة عن الشاشات عبر تقنيات الـ IoT، وإدارة متكاملة للجلسات والمشروبات والمخزون، إضافة لنظام التحديث الذاتي التلقائي (Self-Update) المباشر.

## ✨ المميزات الرئيسية

* ⏱️ **إدارة ذكية للجلسات**: احتساب دقيق لوقت وتكلفة الجلسات الفردية والزوجية، مع دعم فترات Happy Hour والعروض المخصصة تلقائياً.
* 🔌 **تحكم آلي بالكهرباء (IoT Automation)**: دعم الربط مع أجهزة التحكم الذكية لفصل وتشغيل الكهرباء عن الشاشات تلقائياً عند بدء وانتهاء الوقت.
* 🧾 **نظام كاشير ومبيعات متكامل**: إضافة المشروبات والطلبات للجلسات مع إمكانية الدفع النقدي أو الآجل، وطباعة فواتير حرارية (ESC/POS) وتقارير PDF فورية.
* 📦 **المخزون والجرد والمصروفات**: متابعة دقيقة لحركة المنتجات والمخازن وتوريد البضائع وحساب الأرباح والمصروفات اليومية.
* 🏆 **إدارة البطولات والدورات**: تنظيم دورات ألعاب البلايستيشن، وتوزيع المباريات وتصفيات المجموعات وحساب النقاط تلقائياً.
* 🔒 **حماية وأمان متقدم (Screen Lock)**: قفل الشاشات الحساسة بكلمة مرور، ونظام صلاحيات دقيق للمستخدمين لمنع التلاعب.
* 🔄 **تحديثات تلقائية (Self-Update)**: فحص وتحميل التحديثات وتثبيتها تلقائياً بصمت مع التحقق المشفر من بصمة SHA-256 وإعادة التشغيل ذاتياً.
* 🌙 **تصميم مظلم فائق الدقة (Modern Dark UI)**: واجهة عربية بالكامل مصممة بأحدث معايير تجربة المستخدم لتقليل إجهاد العين أثناء العمل لفترات طويلة.
